# Python for Mechanical Engineers

A six-session, project-based workshop by **Dr. Nuha Aljuneidi** for undergraduate and graduate mechanical engineering students.

Students learn Python by solving practical problems in thermodynamics, heat transfer, experimental data analysis, machine learning, simulation, and optimization. No local installation is required; student notebooks run directly in Google Colab.
