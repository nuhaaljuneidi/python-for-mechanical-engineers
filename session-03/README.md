# Session 3 — Engineering Data Analysis with pandas

Students analyze a realistic heat-exchanger test dataset with pandas: inspect and clean measurements, calculate heat-transfer performance, summarize operating conditions, visualize results, and make an evidence-based engineering recommendation.

## Learning outcomes

- load tabular data into a pandas DataFrame;
- inspect data types, missing values, and suspicious measurements;
- clean data using explicit engineering rules;
- calculate heat-transfer rate, heat-capacity rates, and effectiveness;
- group repeated runs and report mean and variability;
- create labeled engineering plots; and
- document assumptions and interpret results.

## Files

- `session-03-student.ipynb` — guided Colab notebook with exercises
- `session-03-solutions.ipynb` — completed instructor version
- `TEACHING-GUIDE.md` — suggested 90-minute lesson plan

## Engineering deliverable

A cleaned performance table, an effectiveness-versus-flow-rate plot with uncertainty bars, and a concise operating recommendation.
